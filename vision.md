# Product Vision

## Vision

OpenSAP Copilot reduces the cognitive effort required to understand and maintain complex enterprise software.

## Core Problem

Enterprise maintenance begins with understanding existing systems safely before changing them. Developers need to know business purpose, execution flow, dependencies, data access, and change risk.

## Target User

The initial user is an SAP ABAP developer who needs to understand an unfamiliar custom program quickly.

Secondary users:

- SAP technical leads
- Functional consultants
- Maintenance teams
- Enterprise architects
- Researchers studying program comprehension

## MVP Outcome

A user uploads a safe sample ABAP file and receives:

- a program-purpose explanation,
- a business-language summary,
- identified tables and dependencies,
- a simplified call flow,
- and a preliminary change-risk assessment.

## Success Criterion

A reviewer should understand the product's value in less than 90 seconds and see a clear path for future development.

## Long-Term Direction

Possible future work includes richer static analysis, CDS and BAPI exploration, repository-level dependency graphs, debugging assistance, performance analysis, test suggestions, and support for additional enterprise languages.
